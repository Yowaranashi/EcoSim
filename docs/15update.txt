3. Расширен контракт мира:
   - ReadModel теперь хранит tick, time, dt, seed, scenario_id, model_id, integrator, species_names, state_vector, metrics, checksum, flags;

4. Создан чистый математический слой:

   - реализован clamp отрицательных и почти нулевых значений;
   - реализован deterministic checksum;
   - добавлен тестовый класс dx/dt = x внутри теста;
   - добавлены тесты Euler, RK4, точности RK4, clamp и checksum.

5. Реализована generalized Lotka-Volterra:
   - добавлен GlvDynamics в src/models/glv_dynamics.h/.cpp;
   - реализована формула dN_i/dt = N_i * (r_i + sum_j(a_ij * N_j) + b_i * u_i(t));
   - поддержаны growth, interaction_matrix, sensitivity, external_input;
   - поддержаны setParameter для growth.<species>, sensitivity.<species>, interaction.<species_i>.<species_j>;
   - реализован applyShock(target, strength);
   - реализованы метрики biomass_total, min_population, max_population, dominant_species_index, species_count;
   - реализован checksum с учетом model_id, species, state, growth, interaction_matrix, sensitivity;
   - реализована матрица Якоби;
   - реализован equilibriumCandidate() для N* = -A^-1*r через Gaussian elimination;
   - добавлены тесты производных, Euler, RK4, Якоби, set_param, shock и checksum.

2. Архитектура и модули

2.1 Application
---------------

Файл: src/core/app.h/.cpp

Назначение:
Application является верхним уровнем приложения. Он загружает конфигурацию, создает EventBus, ModuleRegistry, ModuleManager, Console, регистрирует команды и запускает headless tick-loop.

Основные данные:
   - Logger& logger_: общий логгер;
   - EventBus event_bus_: буферизованная шина событий;
   - AppConfig app_config_: конфигурация приложения;
   - ModuleRegistry registry_: реестр модулей и фабрик;
   - ModuleContext context_: общий контекст для модулей;
   - ModuleManager module_manager_: создание, запуск и остановка модулей;
   - Console console_: консольный интерфейс;
   - bool running_: состояние headless loop;
   - bool console_running_: состояние console loop.

Функции:
   - Application(Logger& logger)
     Вход: logger.
     Выход: объект Application.
     Эффект: инициализирует внутренние подсистемы.

   - ~Application()
     Вход: нет.
     Выход: нет.
     Эффект: очищает EventBus до выгрузки модулей и динамических библиотек.

   - bool initialize(const std::string& config_path)
     Вход: путь к TOML-конфигу приложения.
     Выход: true при успешной загрузке и сборке модулей, false при ошибке.
     Эффект: загружает AppConfig, манифесты модулей, строит набор модулей.

   - bool startModules()
     Вход: нет.
     Выход: true при успешном старте, false при ошибке.
     Эффект: вызывает onStart у модулей через ModuleManager.

   - void runHeadless()
     Вход: нет.
     Выход: нет.
     Эффект: выполняет deterministic tick-loop: pre-tick, tick, post-tick, deliver buffered events.

   - void runConsoleLoop()
     Вход: нет.
     Выход: нет.
     Эффект: запускает консольный режим.

   - void shutdown()
     Вход: нет.
     Выход: нет.
     Эффект: останавливает модули и завершает работу приложения.

   - ModuleManager& moduleManager()
     Вход: нет.
     Выход: ссылка на ModuleManager.

   - ModuleRegistry& registry()
     Вход: нет.
     Выход: ссылка на ModuleRegistry.

   - EventBus& eventBus()
     Вход: нет.
     Выход: ссылка на EventBus.

   - const AppConfig& config() const
     Вход: нет.
     Выход: read-only AppConfig.

   - Console& console()
     Вход: нет.
     Выход: ссылка на Console.

2.5 EventBus
------------

Файл: src/core/event_bus.h/.cpp

Назначение:
Буферизованная шина событий. emit не вызывает подписчиков сразу, а кладет событие в buffer_. Доставка происходит только через deliverBuffered().

Структура SimulationEvent:
   - type: тип события;
   - tick: номер tick;
   - payload: string -> string, старый совместимый payload;
   - numeric_payload: string -> double;
   - string_list_payload: string -> vector<string>;
   - numeric_vector_payload: string -> vector<double>;
   - metrics: string -> double;
   - flags: vector<string>.

Функции:
   - void subscribe(const std::string& event_type, Handler handler)
     Вход: тип события, callback void(const SimulationEvent&).
     Выход: нет.
     Эффект: регистрирует подписчика.

   - void emit(const SimulationEvent& event)
     Вход: событие.
     Выход: нет.
     Эффект: кладет событие в буфер, не доставляет немедленно.

   - void deliverBuffered()
     Вход: нет.
     Выход: нет.
     Эффект: доставляет все buffered events подписчикам и очищает буфер.

   - void clear()
     Вход: нет.
     Выход: нет.
     Эффект: очищает subscribers_ и buffer_.

   - std::size_t bufferedCount() const
     Вход: нет.
     Выход: количество событий в буфере.

2.8 IWorldPort, ReadModel, WorldCommand
---------------------------------------

Файл: src/modules/world_port.h

Назначение:
Контракт доступа к миру для ScenarioRunner и будущих компонентов.

ReadModel:
   - tick: номер tick;
   - time: физическое время tick * dt;
   - dt: шаг времени;
   - seed: seed сценария;
   - scenario_id: идентификатор сценария;
   - model_id: идентификатор модели;

   - checksum: контрольная сумма состояния;
   - flags: служебные флаги;
   - population_by_species: старое совместимое состояние;
   - energy_total: старый совместимый агрегат.

WorldCommand:
   - command: имя команды;
   - params: string -> string;
   - numeric_params: string -> double.

Функции IWorldPort:
   - virtual void enqueueCommand(const std::string& command, const std::map<std::string, std::string>& params)
     Вход: имя команды, строковые параметры.
     Выход: нет.
     Эффект: ставит команду в очередь мира.

   - virtual void enqueueCommand(const WorldCommand& command)
     Вход: типизированная команда.
     Выход: нет.
     Эффект: compatibility default вызывает строковый enqueueCommand.

   - virtual const ReadModel& readModel() const
     Вход: нет.
     Выход: read-only состояние мира.

   - virtual bool shouldStop() const
     Вход: нет.
     Выход: true, если мир просит остановить tick-loop.

2.13 Математический слой: IModelDynamics
----------------------------------------

Файл: src/models/model_dynamics.h

Назначение:
Чистый интерфейс математических моделей. Не зависит от ModuleManager, EventBus, RecorderCsv, OGRE или Application.

Функции:
   - virtual std::string modelId() const
     Вход: нет.
     Выход: идентификатор модели.

   - virtual void configure(const ModelConfig& config)
     Вход: ModelConfig.
     Выход: нет.
     Эффект: настраивает модель, species, state, параметры.

2.15 Математический слой: GlvDynamics
-------------------------------------

Файл: src/models/glv_dynamics.h/.cpp

Назначение:
Реализация generalized Lotka-Volterra:
dN_i/dt = N_i * (r_i + sum_j(a_ij * N_j) + b_i * u_i(t)).

Основные поля:
   - species_names_: имена видов;
   - state_: вектор N;
   - growth_: вектор r;
   - interaction_matrix_: матрица A;
   - sensitivity_: вектор b;
   - external_input_: вектор u;
   - parameters_: карта параметров;
   - flags_: служебные флаги shock.

Функции:
   - void configure(const ModelConfig& config)
     Вход: ModelConfig с species, initial_state, parameters, interaction_matrix.
     Выход: нет.
     Эффект: заполняет N, r, A, b, u; model_id по умолчанию glv.

   - std::vector<double> computeDerivatives(const std::vector<double>& state, double time) const
     Вход: state vector N, time.
     Выход: производные dN/dt.
     Эффект: вычисляет gLV-правую часть.

   - void setParameter(const std::string& name, double value)
     Вход: имя параметра и значение.
     Выход: нет.
     Эффект: поддерживает growth.<species>, sensitivity.<species>, interaction.<species_i>.<species_j>, external_input.<species>.

   - void applyShock(const std::string& target, double strength)
     Вход: species name, strength.
     Выход: нет.
     Эффект: N_target = max(0, N_target + strength), добавляет flag.

   - std::map<std::string, double> getMetrics() const
     Вход: нет.
     Выход: biomass_total, min_population, max_population, dominant_species_index, species_count.

   - std::string checksum() const
     Вход: нет.
     Выход: FNV-1a checksum по model_id, species, state, growth, interaction_matrix, sensitivity.

   - std::vector<std::vector<double>> jacobian() const
     Вход: нет.
     Выход: матрица Якоби J.
     Формула: J_ij = delta_ij * (r_i + sum_k a_ik*N_k + b_i*u_i) + N_i*a_ij.

   - std::optional<std::vector<double>> equilibriumCandidate() const
     Вход: нет.
     Выход: N* для r + A*N = 0 или std::nullopt, если матрица вырождена.
     Эффект: решает систему методом Gaussian elimination.

   - const std::vector<std::string>& getFlags() const
     Вход: нет.
     Выход: read-only список flags.
